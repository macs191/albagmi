# albagmi — Service Hub Desktop

تطبيق عربي لإدارة مواقع الخدمات والمبيعات والمصروفات، يعمل كواجهة ويب وكتطبيق Windows عبر Electron. يدخل كل مكتب باسم مستخدم وكلمة مرور ينشئهما مدير النظام؛ لا يوجد تسجيل ذاتي. يحفظ التطبيق بيانات المكتب في Supabase، مع نسخة محلية مؤقتة على الجهاز.

## الوظائف

- واجهة عربية RTL للصفحة الرئيسية ومواقع الخدمات والبحث والتصنيفات والمفضلة.
- تسجيل المبيعات والمصروفات والتصفية حسب التاريخ وحساب الإجماليات.
- لوحة مدير لإنشاء حسابات المكاتب وتحديد اسم المكتب واسم صاحبه ورقم هاتفه ومدة الاشتراك بالأيام، وتجديد الاشتراكات.
- تنبيه بعد انتهاء الاشتراك بمهلة خمسة أيام، ثم منع الدخول والوصول للبيانات من الخادم حتى التجديد.
- إدارة بيانات المواقع لكل مكتب داخل حسابه؛ اسم المكتب وبيانات صاحبه يديرها المدير.

## التطوير المحلي

```bash
pnpm install
pnpm dev
```

`pnpm dev` يشغل واجهة Vite فقط، ولا يشغّل Vercel Functions. لاختبار الدخول محليًا استخدم بيئة Vercel Functions مع متغيرات البيئة نفسها (مثل `vercel dev`) أو اختبر بعد النشر على Vercel.

## ربط Supabase وVercel

المستودع يحتوي API خادمية في `api/[...path].js` وملف SQL للمخطط في `supabase/migrations/`. أُضيف إلى مشروع Supabase `macs` جدول مستقل اسمه `public.albagmi_accounts` مع RLS، ويقتصر الوصول إليه على الخادم. بيانات وجداول المشروع السابقة لم تُحذف أو تُفرّغ أو تُعدّل.

اربط مستودع GitHub بـVercel، ثم أضف متغيرات `.env.example` في إعدادات المشروع على Vercel. استخدم URL وpublishable/anon key ومفتاح service role من مشروع `macs`. احفظ `SUPABASE_SERVICE_ROLE_KEY` وبيانات المدير و`ALBAGMI_ADMIN_JWT_SECRET` كمتغيرات خادمية فقط؛ لا تبدأ أسماءها بـ`VITE_` ولا تضفها للمستودع أو لملف EXE. بعد ضبطها أعد النشر.

مدير النظام الواحد يُهيّأ من `ALBAGMI_ADMIN_USERNAME` و`ALBAGMI_ADMIN_PASSWORD`. استخدم كلمة مرور قوية وقيمة عشوائية قوية لـ`ALBAGMI_ADMIN_JWT_SECRET`. يسجل المدير الدخول باختيار «مدير النظام» في شاشة الدخول. حسابات المكاتب تُنشأ لاحقًا من اللوحة وتستخدم Supabase Auth؛ لا تحفظ قاعدة التطبيق كلمات المرور كنص أو hash.

## نسخة Electron لنظام Windows

لإنشاء النسخة المحمولة بعد نشر API على Vercel، عرّف `VITE_API_BASE_URL` بعنوان النشر الكامل (مثل `https://your-app.vercel.app`) في بيئة البناء، ثم نفذ:

```bash
pnpm package:win
```

اسمح بطلبات نسخة Electron عبر `ALBAGMI_ALLOWED_ORIGINS` في Vercel. القالب يستخدم `*` لأن المصادقة عبر Bearer token وليس Cookies؛ يمكن استبداله بقائمة Origins موثوقة عند الحاجة. يجب إعادة بناء ملف EXE بعد تغيير رابط API.

## سياسة الاشتراك

يتحقق الخادم من صلاحية الاشتراك عند الدخول وكل طلب قراءة أو حفظ. لا تظهر رسالة التجديد قبل انتهاء الاشتراك. بعد انتهائه تظهر رسالة تحذير بأن أمام العميل خمسة أيام لتجديد الاشتراك؛ بعد نهاية المهلة يرفض الخادم الدخول وقراءة/تعديل بيانات الحساب. التجديد يضيف الأيام إلى تاريخ الانتهاء الحالي إذا لم يكن قد مضى، أو يبدأ من اليوم إذا انتهى سابقًا.
